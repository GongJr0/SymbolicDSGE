# CompiledModel

```python
@dataclass(frozen=True)
class CompiledModel()
```

`CompiledModel` contains the model components mapped to numeric/vectorized/lambdified counterparts.

```python
@dataclass(frozen=True)
class VariableLayout()
```

`VariableLayout` records the dimensions, ordering, and generated variables inferred during compilation.

__Layout Fields:__

| __Name__ | __Type__ | __Description__ |
|:---------|:--------:|----------------:|
| n_var | `#!python int` | Total number of compiled variables. Equal to `n_declared + n_generated`. |
| n_declared | `#!python int` | Number of variables declared in the configuration. |
| n_generated | `#!python int` | Number of lag and lead auxiliaries generated by compilation. |
| n_state | `#!python int` | Number of state variables in canonical order. |
| n_ctrl | `#!python int` | Number of control variables in canonical order. Equal to `n_var - n_state`. |
| n_exog | `#!python int` | Number of shock symbols. This is the width of the shock matrix and `B`. |
| declared_names | `#!python tuple[str, ...]` | Variables in config declaration order. |
| generated_names | `#!python tuple[str, ...]` | Lag and lead auxiliaries created by the compiler, in generation order. |
| canonical_names | `#!python tuple[str, ...]` | Variables in compiled solver order: states first, then controls. |
| state_names | `#!python tuple[str, ...]` | Variables that occur at `t - 1`; these lead canonical order. |
| control_names | `#!python tuple[str, ...]` | Variables not classified as states. |
| idx | `#!python dict[str, int]` | Variable name to canonical index mapping. |
| aux_origin | `#!python dict[str, str]` | Generated auxiliary name to its declared source variable. |
| shock_names | `#!python tuple[str, ...]` | Shock symbols in shock-matrix column order. |
| shock_idx | `#!python dict[str, int]` | Shock symbol to shock-matrix column index mapping. |

`n_state + n_ctrl == n_var`. Dense inputs in declaration order use `declared_names` followed by `generated_names`; canonical arrays use `canonical_names` and `idx`. A generated auxiliary shares its source variable's steady state and variance.
